# PPT Stage Deck (現場雙軌 PPT 導播控場台)

專為現場大型活動、課程、法會與研討會設計之「雙軌雙監視 (PGM/PVW) PPT 導播控場系統」。
提供主副簡報無縫互切、現場投影無黑屏切換、大螢幕文字即時熱修改與多功能獨立視窗控場。

---

## 核心功能

1. **雙軌雙監控 (PGM / PVW)**
   - 左側 PGM 軌即時映射現場大螢幕播出畫面。
   - 右側 PVW 軌供導播人員獨立預覽、跳頁與備妥下一段內容。
   - 按下中央 `CUT` 鍵即可毫秒級無縫互切，現場不黑屏、不穿幫。

2. **原生 PowerPoint COM 自動化引擎**
   - 完整支援 PPT 原生動畫步進與轉場效果。
   - 自動隱蔽原生簡報者檢視畫面，防止視窗遮擋主控介面。
   - 系統安全退出時，自動雙重將系統登錄檔之簡報者檢視畫面設定恢復為啟用狀態。

3. **三大模組獨立視窗自由拖曳**
   - 左側流程隊列、中央雙監視器、下方多功能工作塢均支援點擊右上角按鈕彈出為獨立 Windows 視窗。
   - 透過瀏覽器內部通訊通道跨視窗即時同步，並具備音訊防衝突保護。

4. **自適應縮圖快選與垂直滾動**
   - 簡報縮圖自適應面板寬度，自動排滿每行並保持標準比例。
   - 頁數眾多時支援垂直滾輪順暢滾動，單擊即可於預覽槽快速跳頁。

5. **現場大螢幕文字即時寫回**
   - 支援在工作塢中直接修改投影片文字並寫回，放映視窗即時自動重繪，現場投影無需重新載入。

6. **影音池與安全防護機制**
   - 支援影片插入播出、主視覺 (KV) 一鍵切換與緊急黑屏 (BLACK) 急停。

7. **GitHub 自動版本檢測與一鍵更新**
   - 頂部導航列即時連線 GitHub 比對版本，有新版本時呼吸燈提醒。
   - 支援一鍵線上自動更新（Git 拉取或免安裝版熱覆蓋），素材目錄 100% 絕對保護不遺失。

## 系統需求

- 作業系統：Windows 10 / Windows 11 (64 位元)
- 軟體環境：Microsoft PowerPoint (桌面版)
- 執行環境：Node.js 18 或以上版本（或使用免安裝隨身包）
- 瀏覽器：Microsoft Edge 或 Google Chrome

---

## 快速開始

### 1. 放置素材
請將現場簡報與影音放入對應目錄：
- 簡報檔案 (`.pptx`, `.pptm`, `.ppsm`)：`assets/slides/`
- 影片檔案 (`.mp4`, `.mov`)：`assets/videos/`
- 音訊檔案 (`.mp3`, `.wav`)：`assets/audios/`
- 主視覺底圖 (`.png`, `.jpg`)：`assets/key-visual/`

### 2. 啟動系統
- 雙擊執行 `start-ppt-deck.bat` 或在終端機輸入：
  ```bash
  npm start
  ```
- 瀏覽器將自動開啟主控台介面 (`http://127.0.0.1:8890`)。

---

## 常用操作快捷鍵

- `空白鍵` / `PageDown` / `方向右鍵`：現場 PGM 播放下一頁或下一步動畫
- `PageUp` / `方向左鍵`：現場 PGM 返回上一頁
- `C` 鍵：CUT 切換（PGM 與 PVW 互換）
- `B` 鍵：緊急黑屏切換
- `K` 鍵：主視覺底圖切換
